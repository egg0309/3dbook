## 二、首页视觉系统

首页要与现有 `web` 的遵义会议 3D 书保持同一套气质，不能变成 8 张风格不一的商业海报。

### 2.1 统一色板

| 名称 | 色值 | 用途 |
|---|---|---|
| 深朱砂 | `#4C0A06` | 暗部、书壳、血色记忆 |
| 朱砂 | `#A62B22` | 路线、旗帜、强调 |
| 黄铜金 | `#C8A45C` | 标题字、节点、边框 |
| 旧纸黄 | `#D9C9A8` | 纸张、报纸、地图 |
| 炭黑 | `#0B0908` | 背景、留白 |
| 冷雾蓝灰 | `#5D6B73` | 江水、雪山、夜色 |
| 灯火橙 | `#FFC98F` | 油灯、火把、温暖的人性 |

### 2.2 统一光线与材质

- 低照度电影感，每张场景只有一个明确的暖光源（油灯、火把、晨光）；冷蓝灰做环境对比。
- 粗布、旧纸、黄铜、铁链、木纹、石灰墙、雪、泥沼、报纸油墨。
- 胶片颗粒、轻体积雾、低饱和；不要把画面做成 HDR、霓虹或游戏 CG。
- 每张场景的 **左三分之一压暗、降低细节**，给艺术字、日期和副标题留位置。
- 人物以背影、侧影、群像、剪影为主，不画真实历史人物的可辨识正脸；不渲染血腥。

```

```

### 2.5 首页卡片版式（给美术与前端）

- 场景图：**16:9**，建议 2560×1440，左 36% 压暗留白。
- 标题字：**2:1 透明 PNG**，建议 2048×1024；只放主标题 3–5 个字，日期/副标题由前端用正文字体排。
- 卡片信息：左上角序号、右上角状态（已开放/筹备中）、左下角日期小字 + 艺术字 + 一行副标题。
- 8 张卡片用一条细朱砂“路线”串联；当前“遵义会议”卡片放大或加金色描边，点击进入现有 `web` 展开书页；其余卡片点击显示“筹备中”。
- 首页 Hero 可用 21:9 长征路线主视觉（可选，见第六节），把 8 个节点与 3D 书/遵义会议串起来。

### 2.6 关于 AI 写中文艺术字

AI 直接生成中文标题字的失败率较高，建议按以下顺序处理：

1. 先用本文档的“场景提示词”生成**不含任何文字**的场景底图。
2. 标题字优先找会中文的模型（即梦、Seedream、通义万相等）或设计师；AI 出的字必须人工挑、修、矢量化。
3. 也可用有授权的书法字体做骨架，再叠加墨迹/金箔/锈迹/冰裂纹理；不要直接使用来路不明的商用字体。
4. 标题字最终交付 **透明 PNG**（或 SVG）；如果工具不支持透明，生成在纯黑底上，用亮度转 alpha，并在深浅两种背景上检查边缘。
5. 绝不要让场景 AI 顺带生成标题、报纸正文、地图文字——99% 会变成乱码。

### 01 · 湘江血战

**首页文案**

- 副标题：长征以来最惨烈的一战
- 日期：1934.11—12
- 一句话：湘江两岸，8.6 万红军锐减至 3 万；断后的身影留在对岸。

**史实锚点**
中央红军突破第四道封锁线，在广西兴安一带抢渡湘江；第五次反“围剿”的堡垒对堡垒、分兵抵御和“大搬家”式转移导致惨重损失。这是长征以来最惨烈的一战。

## 六、制作与验收流程

1. **先定顺序与标题**：确认 05 用“抢夺天险”还是“飞夺泸定桥”，06/07 是否按史实对调；标题一旦确定再批量生成。
2. **先场景、后标题**：先生成 8 张无文字场景，统一调色/颗粒；再单独做 8 个标题字，避免 AI 在场景里乱写中文。
3. **标题字**：AI 生成 4–6 个候选 → 挑结构最稳的 → 矢量化/清理 → 加墨迹/金箔/锈迹/冰裂纹理 → 导出透明 PNG；每个标题在 240px 宽和 80px 宽下都要能读。
4. **场景**：按 16:9 生成 → 裁切/扩图 → 左三分之一压暗 → 统一色板/颗粒 → 导出 WebP（≤1.5MB）。
5. **卡片联调**：在 1600×900 和 390×844 下检查标题、日期、副标题、状态标签是否压在安全区；检查 8 张卡片连成路线时不打架。
6. **史实与合规**：团队/指导老师过一遍；不出现真实人物正脸、不血腥、不戏说、不 modern 元素；湘江/雪山草地的牺牲用抽象、庄重的方式。
7. **风格一致性**：8 张场景放在一起看，应该像同一部片子的 8 个章节，而不是 8 个不同的画师。
