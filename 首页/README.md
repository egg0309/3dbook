# 长征之路 · 首页

“星火长征”数字思政育人平台的首页。以一张长征路线地图为主视觉，八个金色标点按历史时间顺序对应八个关键事件；点击标点或底部路线索引，打开该事件的历史档案。遵义会议已接入 `../web` 的 3D 立体书与历史推演智能体，其余事件的互动内容标注为“筹备中”。

## 运行

```bash
cd 首页
npm install
npm run dev
# http://localhost:5174
```

同时启动 3D 展馆（另一个终端）：

```bash
cd web
npm run dev
# http://localhost:5173
```

首页默认把“进入遵义会议”指向 `http://localhost:5173/`。如果 3D 展馆部署在别处，复制 `.env.example` 为 `.env.local`：

```bash
VITE_ZUNYI_URL=https://example.com/zunyi/
```

修改 `VITE_ZUNYI_URL` 后需要重新构建（该变量在构建时注入）。

其他命令：

```bash
npm run build      # tsc + vite 生产构建
npm run preview    # 预览 dist（5174）
npm run assets     # 从 ../首页 的原始美术资产重新生成 public/art
npm run typecheck  # 仅类型检查
```

## 页面结构

- **地图 Hero**：16:9 长征路线地图；金色标点 01—08；于都出发（1934.10.17）与吴起镇（1935.10.19）两个路线端点；窄屏可左右滑动地图。
- **路线索引**：底部横向索引，按时间顺序列出八个事件；已浏览的事件会显示对勾（`localStorage` 记录）。
- **八个历史坐标**：8 张场景卡，展示标题字、日期、地点与摘要；点击打开同一份历史档案弹窗。
- **关于长征**：长征精神与关键数据；提供进入遵义会议 3D 展馆的入口。
- **历史档案弹窗**：场景图、标题字、日期/地点、史实脉络、关键节点、历史意义、上一站/下一站；支持键盘 `Esc` 关闭、`←` / `→` 切换站点，打开时锁定页面滚动。

## 八个阶段与史实顺序

| 序号 | 事件 | 时间 |
|---|---|---|
| 01 | 湘江血战 | 1934.11.27—12.01 |
| 02 | 通道会议 | 1934.12.12 |
| 03 | 遵义会议 | 1935.01.15—01.17 |
| 04 | 四渡赤水 | 1935.01.19—03.22 |
| 05 | 抢夺天险（巧渡金沙江 · 飞夺泸定桥） | 1935.05 |
| 06 | 雪山草地 | 1935.06—08 |
| 07 | 哈达铺 | 1935.09.18—09.22 |
| 08 | 三军会师 | 1936.10.09 / 10.22 |

几个刻意的史实处理：

- `场景(1).docx` 里“哈达铺”在“雪山草地”之前；本页按历史时间顺序调整为 **06 雪山草地 → 07 哈达铺**。
- 地图主路线是 **中央红军 1934.10—1935.10 的长征路线**，终点为吴起镇。三军会师发生在 1936.10 的会宁、将台堡，不在中央红军 1935 年的主路线上，因此 08 用**金色虚线支线**从主路线引出，并标注“1936.10 三军会师方向”，避免把两个时间层混在一起。
- 地图为历史示意，路线与坐标经过艺术化处理；页面底部和路线索引下方都有说明。事件日期、地点、部队与关键节点按公开党史资料整理。
- “抢夺天险”按原始文档保留为主标题，副标题为“巧渡金沙江 · 飞夺泸定桥”；详情内同时列出巧渡金沙江（1935.5.3—9）、强渡大渡河（5.25）和飞夺泸定桥（5.29），避免用一个日期概括整段行动。

## 美术资产

原始素材在本目录下的中文文件夹（`湘江血战/`、`通道会议/`……），构建前由脚本处理成网页用 WebP：

```bash
npm run assets
```

脚本 `scripts/prepare-assets.mjs` 会：

- 把地图裁成 1600×900，叠加左侧/顶部暗部渐变，遮住原始占位灰块，输出 `public/art/map.webp`；
- 裁掉标题字的透明边距，输出 1500px 宽的透明 WebP；
- 把场景图压到 1800px 宽、质量 84 的 WebP；
- 输出到 `public/art/stages/<id>/title.webp` 与 `scene*.webp`。

页面只引用 `public/art/`，不直接读取中文源文件；替换美术资产时保留同名文件，或在 `src/data/stages.ts` 里改路径。

## 部署

```bash
npm run build
```

产物在 `dist/`。Vite 使用 `base: './'`，可直接把 `dist/` 放到任意静态目录；`art/` 用相对路径加载。若从子路径部署，构建前设置：

```bash
# .env.local
VITE_ZUNYI_URL=/zunyi/
```

`web/` 是独立的 3D 展馆工程，生产环境建议和首页同域部署，再把 `VITE_ZUNYI_URL` 指向它的实际路径。

## 已验证

- 320 / 360 / 390 / 414 / 768 / 1024 / 1280 / 1440 / 1600 / 1920 / 3440 宽度无横向溢出。
- 390 下地图可左右滑动，初始定位在 05 附近；八个标点均可点击。
- 八个历史档案均能打开；雪山草地可切换“雪山/草地”场景。
- 键盘：`Esc` 关闭、`←` / `→` 切换、Tab 焦点循环；关闭后焦点回到打开的标点，页面滚动恢复。
- 构建产物中所有图片加载成功，无控制台错误。

## 已知限制

- 除遵义会议外，其余七站只有史实档案，没有独立互动内容。
- 首页不调用后端；3D 展馆的智能体仍由 `web/` 和 `docs/AGENT_INTEGRATION.md` 的契约驱动。
- 地图是艺术化示意，不是 GIS 地图；如需严格地理定位，应换成有授权的地理底图并重新标点。
- 美术资产为 AI 辅助生成，人物与场景为艺术再现；请团队按比赛/出版要求确认版权与史实审校。
