# 🧪 遵义会议红色教育智能体 · 测试工作目录

> 对应方案：`../docs/TEST_DATA_DESIGN.md`
> 设计原则：**机器能判的交给脚本，人要判的必须留痕**。两部分物理分开，避免"脚本跑绿了就当测试过了"。

---

## 一、两条流水线

```
L1 契约测试   ──(pytest)────────────────────────────► 全自动，0 token，门禁 100%
L3 红队扫描   ──(脚本投喂+初筛)──► 人工终审 ──► 加固 ──► 全量回归
L2 生成采样   ──(脚本采样)───────► 人工评分 ──► 改 prompt/约束 ──► 重采样
L4 真人测试   ──(人施测+填表)────► 数据录入 ──► 脚本统计 ──► 门禁判定
```

关键边界：

| 环节 | 脚本负责 | 人负责 |
| --- | --- | --- |
| L1 | 全部 | 无需介入（只看红绿） |
| L2 | 采样、字数/禁用词初筛 | **四个维度的最终判定** |
| L3 | 投喂、关键词初筛、出待审清单 | **终审判定 + 定加固方案** |
| L4 | 施测后的统计计算 | **施测、记录、编码开放题** |

## 三、执行顺序（建议）

| 阶段 | 命令/动作 | 产出 | 出口标准 |
| --- | --- | --- | --- |
| ① 接入 | 改 `adapters.py` + 换 fixtures | L1 指向真实系统 | 真实系统下 L1 仍全绿 |
| ② 契约 | `make l1` | 34 项通过 | **100%** |
| ③ 采样 | `make l2` | `runs/L2_runs_*.jsonl` | 样本数达标 |
| ④ 评分 | 人工填 `评分表.csv` | 通过率 | 见评分规则第三节 |
| ⑤ 红队 | `make l3` → 人工终审 | `reports/L3_scan_*.csv` | LEAK = 0 |
| ⑥ 加固回归 | 改词表/规则 → `make l1 l3` | `回归记录.md` | 全绿 + 归档 |
| ⑦ 可用性 | 8–10 人，填 `观察记录表.csv` | 卡点清单 | T1/T2 ≥ 80% |
| ⑧ 效果 | 30–50 人，填 `pre_post.csv` / `survey.csv` | 知识增益 | 门禁阈值由项目组定 |
| ⑨ 报告 | `make analyze` | `L4_analysis_*.json` | 汇总进 PPT |

## 四、常用命令

```bash
cd tests
make l1        # 契约测试（无需网络/模型）
make l2        # L2 采样（需 LLM_ENDPOINT）
make l3        # L3 红队（需 LLM_ENDPOINT）
make analyze   # L4 统计（需先录入数据）
make check     # 只做样本集结构校验（dry-run，不调模型）
```

环境变量：

```bash
export LLM_ENDPOINT="http://your-endpoint/v1/chat/completions"
export LLM_API_KEY="sk-..."
export LLM_MODEL="your-model"
```

## 五、接入真实系统的唯一改动点

`01_机器执行/01_L1_契约测试/adapters.py` 里的 `ReferenceAgent`，替换三个方法体：

| 方法 | 契约 |
| --- | --- |
| `select(choice, session)` | 非法输入返回 `ok=False/advanced=False` 且不推进；LLM 异常回退 baseline 并置 `fallback=True` |
| `build_review(session)` | 返回复盘文本（受字数与禁用词约束） |
| `judge_profile(tier_sequence)` | 与线上画像规则表一致 |

**测试文件不要改。** 如果为了跑绿而改测试，等于取消了测试。

## 六、三条纪律（答辩前必读）

1. **dry-run 数据不得进答辩**：无 `--endpoint` 跑出来的 `[DRY-RUN]` 记录只是占位，`make check` 也不产生可用数据。
2. **规模是目标不是成果**：L1 40 条断言、L2 30×5、L3 50 条、L4 30–50 人，均为设计目标；未做完就写"未完成"，不得写"已通过"。
3. **结论必须能溯源**：每一个"通过"都要能指到具体文件的具体行（哪条样本、哪次采样、谁判的）。
